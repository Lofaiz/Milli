# Милли

Голосовой помощник поверх [OpenCode](https://opencode.ai): маленькое окно в трее,
микрофон, локальное распознавание речи и ответы модели. Написана на C# под
Windows, распознавание работает внутри программы.

Английская версия инструкции — [installer/README.en.txt](installer/README.en.txt).

## Что нужно

1. Windows 10 или 11 (64 бита).
2. Установленный и настроенный OpenCode — Милли общается именно с ним.
   Если OpenCode не запущен, ответов не будет: окно покажет ошибку связи.
3. Микрофон (встроенный или внешний).
4. Процессор с поддержкой AVX (Intel с 2011 года, AMD FX/Ryzen и новее).

## Установка

Готовые файлы — в разделе [Releases](../../releases):

| Файл | Что это |
| --- | --- |
| `MilliSetup.exe` | установщик, права администратора не нужны |

Установщик ставит программу в профиль пользователя
(`%LOCALAPPDATA%\Programs\Milli`), добавляет ярлыки в меню «Пуск» и на рабочий
стол, по желанию — автозапуск при входе. Удаление: «Пуск» → «Удалить Милли» или
«Параметры» → «Приложения».

## Как пользоваться

- Милли запускается и сразу прячется в трей. Двойной клик по значку — показать
  или убрать окно.
- **Голос:** зажмите клавишу голосового ввода (по умолчанию **Num 9**), говорите,
  отпустите. Милли распознает и сразу отправит текст.
- **Окно:** клавиша **Num 8**.
- Можно и без голоса: наберите текст в поле ввода и нажмите Enter.
- Кнопка «🎤 Голос» работает так же, как клавиша: держите мышью, пока говорите.

Клавиши, модель и язык меняются в трее (правый клик по значку):

| Пункт | Что делает |
| --- | --- |
| «Настройки клавиш…» | назначить свои клавиши |
| «Модель ИИ…» | какой моделью отвечает Милли |
| «🎧 Модель распознавания…» | какую модель распознавания речи использовать |
| «Голос → отправлять сразу» | отправлять распознанное сразу или вставлять в поле |
| «Язык» → «Русский» / «English» | язык интерфейса |

## Стоп, команды и напоминания

- «⏹ Стоп» — кнопка в окне и пункт в трее: прервать длинный ответ. Голосом:
  «стоп», «хватит», «остановись» (stop, enough, cancel).
- «повтори», «ещё раз» (repeat, say it again) — повторить последний ответ.
- «новый разговор», «очисти чат» (new conversation, clear chat) — начать заново.

Справочные команды выполняются сразу, без обращения к модели, и понимаются на
обоих языках:

```
«сколько времени», «какое сегодня число», «какой сегодня день недели»
«открой блокнот», «открой хром», «открой документы», "open downloads"
```

Приложения — белый список (Opera GX, Chrome, Edge, Discord, Telegram, Steam,
Epic, OpenCode, qBittorrent, FileZilla, WinRAR, 7-Zip, LM Studio, IntelliJ и
стандартные Windows), плюс папки «Документы», «Загрузки», «Рабочий стол».
Незнакомое название Милли передаёт модели как обычный вопрос.

Напоминания:

```
«напомни через 10 минут позвонить маме»
«напомни через полчаса выключить плиту»
"remind me in 2 hours to check mail"
```

Понимаются минуты, часы, «полчаса», «полтора часа», составные сроки. Напоминание
придёт в трей и в переписку.

## Язык

Язык выбирается в трее и меняет сразу всё: подписи в окне и диалогах, язык
распознавания речи, язык ответов и подпись Милли в переписке. Выбор сохраняется
в `config.json` (ключ `language`) и не сбрасывается при обновлении.

## Модели распознавания

В комплекте две модели, они лежат в папке `model` рядом с программой:

- `ggml-base-q5_1.bin` — быстрая (около 4 секунд на слабом ноутбуке), по умолчанию;
- `ggml-small-q5_1.bin` — точнее, но заметно медленнее (до 15 секунд на фразу).

Переключение: трей → «🎧 Модель распознавания…». Свои модели: положите в папку
`model` любой `ggml-*.bin`, он появится в списке.

## Настройки

`config.json` лежит рядом с программой (в папке установки). Если писать туда
нельзя, настройки уходят в `%LOCALAPPDATA%\Milli\config.json`.

| Ключ | Значение |
| --- | --- |
| `title` | подпись Милли в переписке |
| `model` | модель ИИ (`id` и `providerID` от OpenCode) |
| `language` | язык интерфейса, распознавания и ответов (`ru` или `en`) |
| `sttModel` | файл модели распознавания из папки `model` |
| `autoSendVoice` | отправлять распознанное сразу или вставлять в поле |
| `startHidden` | запускаться скрытно, в трей |
| `cleanSessions` | при запуске убирать старые сессии Милли из OpenCode |
| `hotkeyVoice` | клавиша голосового ввода, например `Num9` или `Ctrl+F7` |
| `hotkeyWindow` | клавиша показа окна, например `Num8` или `Ctrl+F8` |
| `persona` | характер Милли, служебная инструкция для модели |

Старые разговоры Милли убираются из OpenCode при каждом запуске — остаётся
только текущая сессия. Отключается: `cleanSessions: false`.

## Диагностика

Проверить распознавание на готовом wav-файле (микрофон не нужен):

```
Milli.exe --say-file "C:\путь\к\файлу.wav"
```

Служебные ключи: `--lang en`, `--menu`, `--model`, `--stt`, `--clean-sessions`,
`--keys` — открывают соответствующий диалог или действие.

## Сборка из исходников

Нужны [.NET SDK 10](https://dotnet.microsoft.com/download) и, для установщика,
[Inno Setup 6](https://jrsoftware.org/isdl.php).

```
powershell -ExecutionPolicy Bypass -File "Собрать-сборку.ps1"
```

Скрипт сам скачает недостающие модели распознавания, соберёт приложение в
`publish` и упакует `installer\MilliSetup.exe`. Только приложение, без
установщика:

```
powershell -ExecutionPolicy Bypass -File "Собрать-сборку.ps1" -NoInstaller
```

Модели в репозитории не хранятся — это большие бинарные файлы, они скачиваются
из [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp).

## Если что-то не работает

- **Клавиши не срабатывают** — их заняла другая программа. Трей →
  «Настройки клавиш…». Пока окно Милли открыто, клавиши работают всё равно.
- **«OpenCode не отвечает»** — проверьте, что OpenCode запущен и вы в него вошли.
  После перезапуска OpenCode Милли найдёт его сама через пару секунд.
- **«Недостаточно средств»** — это про платную модель. Трей → «Модель ИИ…»,
  выберите бесплатную.
- **Ничего не слышно** — проверьте микрофон и разрешение в «Параметры →
  Конфиденциальность → Микрофон».
- **Слышит, но пишет ерунду** — язык в трее должен совпадать с тем, на котором
  вы говорите.
